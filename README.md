#  Perplexity AI Chat Application

A full-stack AI-powered chat application inspired by Perplexity AI, built with the MERN stack. The application provides secure user authentication, AI-generated conversations, chat history management, and a modern responsive interface.

##  Features

* 🔐 JWT-based user authentication
* 📧 Email verification during registration
* 🤖 AI-powered chat responses using Google Gemini
* 📝 Automatic chat title generation using Mistral AI
* 💬 Create, continue, and manage multiple conversations
* 🗂️ Chat history with delete functionality
* ⚡ Responsive and modern dark-themed UI
* 🔒 Protected routes and secure API endpoints
* 📢 Toast notifications and loading states
* ⌨️ Keyboard shortcuts for faster messaging
